Movie-List --- Movie Discovery Platform 

Live Demo: https://movie-list-eight.vercel.app

A fast, responsive movie/TV show browsing experience built for discovery.

## Features
- Browse trending movies & TV shows
- Search with instant results
- Clean, Netflix-style grid UI
- Mobile responsive

## Tech Stack
- React + Vite
- TailwindCSS for styling
- Zustand for state management
- TanStack React Query for data fetching & caching
- TVmaze API
- Vercel for deployment

## How to run locally
npm install
npm run dev
